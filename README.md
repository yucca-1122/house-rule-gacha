# 改造ルールガチャ

ボードゲームのいつものルールに飽きたときに、ハウスルール（改造ルール）をランダムに引いて遊ぶためのページ集です。
いまは **カタン（通常版・3〜4人）** のハウスルールが215種入っています。かんたんなちょい足しから、頭が爆発する鬼ルールまで5段階あります。

**遊ぶ**: https://yucca-1122.github.io/house-rule-gacha/

## 入っているゲーム

| ゲーム | ルール数 | 難易度 |
|---|---|---|
| [カタン改造ルールガチャ](games/catan/) | 215 | ★1 かんたん（62）／★2 ふつう（69）／★3 むずかしい（46）／★4 激ムズ（23）／★5 鬼（15） |

## 使い方

1. 難易度（★1〜★5）・枚数（1〜5枚）・人数を選んで「ガチャを回す」
2. 気に入らないカードは「引き直す」、いらないカードは「外す」。「1枚足す」で今の組に追加
3. 「テキストでコピー」で、引いたルールをそのままチャットに貼れる
4. 「ぜんぶ見る」で全ルールを検索・しぼりこみ。「遊び方」に難易度の目安・おすすめの引き方・基本ルールの早見表
5. 遊んでいる間は「画面をつけたままにする」をオンにして机に置ける
6. 「持ち時間」タブの持ち時間ガチャで、1手番の持ち時間を変えるカードを1枚引ける（ルールのカードとは別。「テキストでコピー」にも入る）

同時に使うと矛盾するルール（例: 「盗賊なし」と「盗賊2体」）は、同じ組に出ないようにしてあります。
設定と履歴はそのブラウザの中にだけ保存され、どこにも送信されません。

## 手元で開く

このリポジトリをダウンロードして `games/catan/index.html` をブラウザで開くだけで動きます（書体はネットから読み込みます）。

## ゲームを足す

手順は [docs/ゲームの足し方.md](docs/ゲームの足し方.md) にあります。
`games/<ゲームのID>/rules.js` にルールを書いて `node tools/build.mjs` を実行すると、そのゲームのページと一覧が作られます。画面の本体（`app/gacha.html`）は全ゲームで共通です。
持ち時間ガチャ（`rules.js` の `timer`）は任意で、書いたゲームにだけ「持ち時間」タブが出ます。

## 構成

| 場所 | 中身 |
|---|---|
| `index.html` | ゲームの一覧（`tools/build.mjs` が作る） |
| `app/gacha.html` | 画面の本体（全ゲーム共通） |
| `games/<ID>/rules.js` | そのゲームのルールのデータ |
| `games/<ID>/pairs.json` | 両立判定の確認に使う組（任意） |
| `games/<ID>/index.html` | そのゲームのページ（`tools/build.mjs` が作る） |
| `tools/` | ページを作るスクリプトと、データの検査 |
| `docs/` | ゲームの足し方 |

## 検査

Node.js があれば、追加のインストールなしで動きます。

```
node tools/check_rules.mjs games/catan   # データの検査（番号・重複・ジャンル・両立判定の語彙）
node tools/check_pairs.mjs games/catan   # 両立判定の確認（同時に出てはいけない組・出てよい組）
node tools/build.mjs                     # ページを作り直す
```
